# Architecture

```text
birth input
-> L0 deterministic calculation
-> validation and minute sensitivity
-> four independent native dossiers
-> dossier challenge
-> competing life hypotheses
-> cross-school adjudication
-> four-dimensional scoring
-> Traditional Chinese Reader
-> Markdown / Dashboard PDF
```

L0 contains facts only. Native dossiers preserve each school's method. Adjudication may read approved dossiers but must not reinterpret raw placements. Reader prose may read adjudication and scores but must not create new technical claims or dates.

The bundled calculator covers all four systems. Vedic uses `scripts/vedic_engine` first and accepts `VEDIC_CALCULATOR_DIR` only as an optional override or compatibility fallback.

The agent owns interpretation. Deterministic scripts own calculation, schema checks, scoring and rendering.
